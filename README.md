# Kit-numbers
Утилита для поиска чисел Кита и бенчмаркинга производительности ПК. Реализует быстрый алгоритм со скользящим окном и чистую ООП-архитектуру. Позволяет задавать любой диапазон, валидирует ввод и точно замеряет время вычислений. Идеальный инструмент для математических исследований и стресс-тестов процессора.
